# Поиск клиентов: салоны без сайта → Telegram

Бот находит действующие салоны красоты в Ереване без своего сайта и присылает вам карточку:
название, адрес, телефон, Facebook/Instagram, ссылки на WhatsApp/Telegram и Google Maps,
почему салон подходит и готовый текст (армянский или русский).

Салоны берутся из **Overture Maps** — открытой базы мест (данные Meta/Facebook, Microsoft и др.).
Бесплатно, без ключей, без банковской карты и без лимитов. База обновляется раз в месяц,
бот сам подхватывает новый выпуск. Отзывов в ней нет: «живость» салона оценивается по
`confidence` (уверенность базы, что место работает). Отзывы можно глянуть кнопкой **Google Maps**.
**Отправляете вы сами** — бот ничего салонам не пишет.

## Файлы

| Файл | Что делает |
|---|---|
| `bot.py` | Telegram-бот + фоновое пополнение очереди. Это то, что запускаете |
| `finder.py` | Загрузка салонов из Overture Maps и фильтр |
| `writer.py` | Текст через Claude, запасной вариант — Gemini |
| `db.py` | База `data.db`: каждый салон один раз, статусы |
| `niches/beauty_salons.json` | Ниша: города, категории, фильтр, ваш оффер, шаблон текста |
| `.env` | Ваши ключи (создаётся из `.env.example`) |

## Установка (один раз)

### 1. Библиотеки Python
Откройте PowerShell в этой папке:
```powershell
python -m pip install -r requirements.txt
```

### 2. Telegram-бот
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя.
2. Скопируйте токен вида `123456:ABC...`.

### 3. Ключ Gemini (запасной ИИ, бесплатно, без карты)
https://aistudio.google.com/apikey → **Create API key**.

### 4. Claude Code — основной ИИ для текстов (по вашей подписке Claude)
```powershell
irm https://claude.ai/install.ps1 | iex
```
Закройте и откройте PowerShell заново, затем один раз войдите в аккаунт:
```powershell
claude
```
Проверка (должен прийти ответ):
```powershell
claude -p "Скажи привет по-армянски"
```
Если Claude не настроен или кончился лимит подписки — бот сам перейдёт на Gemini.

### 5. Файл .env
```powershell
copy .env.example .env
notepad .env
```
Впишите `TELEGRAM_TOKEN` и `GEMINI_API_KEY`. `OWNER_ID` пока оставьте пустым.

### 6. Ваш оффер
```powershell
notepad niches\beauty_salons.json
```
В блоке `my_offer` замените три строки «ЗАПОЛНИТЕ…»: что входит в сайт, цену и ссылку на пример.

### 7. Ваш Telegram ID
```powershell
python bot.py
```
Напишите боту `/start` — он пришлёт ваш ID. Остановите бота (Ctrl+C), впишите ID в `.env`
в строку `OWNER_ID=` и запустите снова. Теперь бот отвечает только вам.

## Каждый день

Два клика:
- **`start.bat`** — запустить бота **в фоне**. Окно само закроется через несколько секунд,
  а бот продолжит работать (его не видно, он живёт в фоне, пока включён компьютер);
- **`stop.bat`** — остановить бота.

Журнал работы бота — файл `bot.log` (если что-то не так, смотрите его).
После перезагрузки компьютера бот не запускается сам — запустите `start.bat` снова.

Запустить второго бота при работающем первом нельзя: `start.bat` сам откажется.
Или вручную: `python bot.py` в PowerShell.

Компьютер должен быть включён.

В Telegram:
- `/next` — следующий салон. Кнопки: **✅ Написал**, **⏭ Пропустить**, **🚫 Не подходит**,
  **Текст на русском/армянском**. Ссылка **WhatsApp** открывает чат с уже вставленным текстом.
- `/regions` — **выбрать регионы**: города Армении и крупные города России, можно несколько
  или сразу всю страну. Выбор сохраняется. `/next` даёт салоны только из выбранных регионов.
  Новый регион загружается в фоне примерно за минуту (Москва дольше).
- `/stats` — сколько найдено и написано (по выбранным регионам).

Каждый салон показывается один раз. Даже если не нажали кнопку — он больше не придёт.

## Настройка

Всё в `niches/beauty_salons.json`, код трогать не надо:
- **ещё город** — добавьте в `cities` строку вида
  `{"id": "stepanakert", "name": "Название", "country": "AM", "in_ru": "в Названии", "bbox": [запад, юг, восток, север]}`
  (координаты можно взять на https://bboxfinder.com). Он сразу появится в `/regions`.
  Новая страна — добавьте её в `countries`, `languages` и `templates`;
- **другие виды бизнеса** — `categories` (названия категорий Overture: `beauty_salon`, `barber`, `dentist`…);
- **строже/мягче фильтр** — `min_confidence` (0.75 сейчас; 0.6 — больше салонов, но больше закрытых);
- **стиль текста** — `prompt`;
- **языки по странам** — `languages` (первый язык — по умолчанию): Армения `hy` + `ru`, Россия только `ru`;
- **тексты шаблона** — `templates` по странам (`AM`, `RU`); `{name}` — название салона, `{in_city}` — «в Гюмри», «в Москве»…

**Новая ниша** (например, стоматологии): скопируйте файл в `niches/dentists.json`,
поменяйте категории, оффер и текст, в `.env` поставьте `NICHE=dentists`, перезапустите бота.
Статистика и «без повторов» у каждой ниши свои.

## Если что-то не так
- **«Очередь пуста»** — подождите минуту и снова `/next`; в `/stats` видно, что делает поиск и нет ли ошибки.
- **Ошибка Gemini 404** — поменяйте `GEMINI_MODEL` в `.env` на модель из списка на https://aistudio.google.com.
- **Начать с нуля** — остановите бота и удалите `data.db` (салоны снова начнут показываться).

## Режимы текста

В `niches/beauty_salons.json`, блок `text`:
- `"mode": "template"` — **фиксированный шаблон** (сейчас). Тексты на двух языках лежат в `templates`,
  вместо `{name}` подставляется название салона. ИИ не нужен, `/next` отвечает мгновенно.
  Хотите поменять текст — правьте `templates`.
- `"mode": "ai"` — каждый текст пишет ИИ под конкретный салон (нужен Claude Code или ключ Gemini).

## Установка на другом компьютере через ИИ

Репозиторий: https://github.com/kirakosyangeorgi2010-art/work_bot

Откройте Claude Code (или другого ИИ с доступом к терминалу) в пустой папке и вставьте:

```
Скачай проект https://github.com/kirakosyangeorgi2010-art/work_bot (git clone, нужен вход в GitHub: gh auth login),
прочитай в нём файл CLAUDE.md и разверни проект по инструкции. Мои ключи: токен НОВОГО Telegram-бота для этого компьютера <...>,
ключ Gemini <...> (или не нужен), мой Telegram ID <...> (или найди через /start). Запусти бота и проверь.
```

**У каждого компьютера свой бот:** создайте нового бота у @BotFather (`/newbot`) и дайте ИИ его токен.
Боты независимы, у каждого своя база `data.db` и своя история. В репозитории **нет** файлов `.env` (ключи)
и `data.db`.

Чтобы разные боты не показывали вам одни и те же салоны, разделите районы/города между ними:
подробности в `CLAUDE.md`, раздел «Несколько компьютеров».
