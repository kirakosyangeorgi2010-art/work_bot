# Инструкция для ИИ: установка и запуск проекта на новом компьютере

Это Telegram-бот для поиска клиентов (салоны красоты в Ереване без своего сайта).
Он находит салоны в открытой базе Overture Maps, фильтрует их, и по команде `/next`
присылает владельцу карточку салона с готовым текстом. Сообщения салонам бот **не отправляет**:
владелец отправляет их вручную. Подробности для человека — в `README.md`.

Твоя задача: развернуть проект на этом компьютере, получив от пользователя ключи, и запустить бота.

## Что нужно спросить у пользователя

Спроси всё одним сообщением. Ничего не выдумывай и не используй чужие ключи.

1. **`TELEGRAM_TOKEN`**: токен бота от @BotFather (вид `123456789:AA...`).
   Если пользователь хочет оставить прежнего бота (@bleaze_work_bot), токен тот же.
   Если нет бота: пусть напишет @BotFather команду `/newbot` и пришлёт токен.
2. **`GEMINI_API_KEY`**: ключ с https://aistudio.google.com/apikey (бесплатно, без банковской карты).
   Нужен только для режима текста `"mode": "ai"` и как запасной. В текущем режиме
   `"mode": "template"` (фиксированный шаблон) ключ **не используется**, его можно не спрашивать
   и оставить пустым.
3. **`OWNER_ID`**: Telegram ID владельца (число). Бот отвечает только ему. Если пользователь его
   не знает: запусти бота без `OWNER_ID`, пусть напишет боту `/start`, бот пришлёт ID,
   после этого впиши ID и перезапусти бота.
4. Нужно ли сохранить историю (какие салоны уже показаны/отмечены)? Если да, файл `data.db`
   надо скопировать со старого компьютера вручную (в репозитории его нет). Без него бот
   загрузит салоны заново, и уже показанные будут показаны снова.

Платные ключи и банковские карты не нужны. Поиск салонов (Overture Maps) работает без ключа.

## Шаги установки (Windows)

1. Убедись, что установлен **Python 3.10+**: `python --version`. Если нет, поставь с python.org
   (отметить «Add python.exe to PATH») и открой новый терминал.
2. Установи зависимости из папки проекта:
   ```powershell
   python -m pip install -r requirements.txt
   ```
3. Создай `.env` из примера и впиши полученные значения (кодировка UTF-8, без кавычек вокруг значений):
   ```powershell
   copy .env.example .env
   ```
   Заполни строки `TELEGRAM_TOKEN=`, `OWNER_ID=`, `GEMINI_API_KEY=`. Остальные оставь как в примере.
   Не показывай значения ключей в ответах пользователю, не печатай их в логах, не коммить `.env`.
4. Проверь без ключей и интернета:
   ```powershell
   python test_offline.py
   ```
   Ожидаемо: строки `OK ...` и в конце «Всё в порядке».
5. Проверь поиск салонов (нужен интернет, около 30 секунд, ничего не пишет в базу):
   ```powershell
   python finder.py
   ```
   Ожидаемо: выпуск Overture, число мест (~1000) и список подходящих салонов (✅).
6. Если используется режим `"ai"`: проверь тексты командой `python writer.py`.
   В режиме `"template"` этот шаг не нужен.
7. Проверь токен Telegram:
   ```powershell
   python -c "import os, requests; from dotenv import load_dotenv; load_dotenv('.env'); print(requests.get('https://api.telegram.org/bot'+os.environ['TELEGRAM_TOKEN']+'/getMe', timeout=20).json().get('ok'))"
   ```
   Ожидаемо: `True`.
8. Запусти бота: двойной щелчок по `start.bat` (или `.\start.bat`). Бот работает **скрытно в фоне**,
   окно закрывается само, журнал пишется в `bot.log`. Остановить: `stop.bat`.
9. Попроси пользователя написать боту `/start`, затем `/next`. Должна прийти карточка салона и
   отдельным сообщением текст. Первая загрузка салонов занимает около 30 секунд.

На Linux/macOS: `python3 bot.py` (в фоне, например, `nohup python3 -u bot.py > bot.log 2>&1 &`).
Файлы `.bat` работают только в Windows.

## Важные правила и подводные камни

- **Один токен: один запущенный бот.** Если бот работает на другом компьютере, а здесь запустить
  тот же токен, Telegram вернёт ошибку `409 Conflict`. Сначала останови старого (`stop.bat`
  на старом компьютере).
- **Секреты:** `.env`, `data.db` и `bot.log` в `.gitignore`. Никогда не добавляй их в git и не
  вставляй значения ключей в файлы проекта, README или коммиты. Если ключ случайно попал в чат
  или репозиторий, скажи пользователю перевыпустить его (BotFather: `/revoke`; Gemini: удалить
  ключ и создать новый).
- **Отправка салонам только вручную.** Не добавляй автоотправку сообщений и парсинг
  Instagram/Facebook: это приведёт к блокировкам аккаунтов.
- **Цену в текстах не называем**, это решение владельца.
- **Файлы `.bat`:** сохранять в UTF-8 **без BOM**, окончания строк CRLF. С BOM или с неверной
  кодировкой кириллица в `cmd` ломается, а первая команда не выполняется.
- Сам бот в Windows запускается как `python -u bot.py`; поиск процесса идёт по
  `python*` и `bot.py` в командной строке (так работают `start.bat` и `stop.bat`).

## Устройство проекта (коротко)

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот (`/start`, `/next`, `/stats`, кнопки) и фоновое пополнение очереди |
| `finder.py` | Загрузка мест из Overture Maps (DuckDB) и фильтр «нет сайта, работает, есть контакт» |
| `writer.py` | Текст сообщения: шаблон (`template`) или ИИ (`ai`: Claude Code, затем Gemini) |
| `db.py` | SQLite `data.db`: салоны, статусы, без повторов |
| `niches/beauty_salons.json` | **Ниша**: города (bbox), категории, фильтр, оффер, шаблоны текстов |
| `start.bat`, `stop.bat` | Запуск в фоне и остановка (Windows) |
| `test_offline.py` | Проверка фильтра и базы без интернета |

**Новая ниша или город:** не меняй код, копируй/правь JSON в `niches/` и укажи `NICHE=имя_файла`
в `.env` (подробности в `README.md`).

**Режим текста:** в `niches/beauty_salons.json` в блоке `text` поле `"mode"`:
`"template"` — фиксированные тексты `templates.ru` / `templates.hy` с подстановкой `{name}`;
`"ai"` — уникальный текст через ИИ. Для `"ai"` нужен Claude Code
(`irm https://claude.ai/install.ps1 | iex`, затем один раз войти командой `claude`) и/или `GEMINI_API_KEY`.

**Оффер** (что входит в сайт, ссылка на пример) лежит в блоке `my_offer` того же файла. Он уже заполнен;
если пользователь хочет другой, поменяй `includes` и `example_url`.

## Когда всё готово

Сообщи пользователю: бот запущен, как его остановить (`stop.bat`), где журнал (`bot.log`),
и что после перезагрузки компьютера бот сам не стартует: нужно снова запустить `start.bat`.
